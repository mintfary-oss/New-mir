## Технологический словарь
Программирование — написание программ для компьютеров.
Нейросеть — система искусственного интеллекта, обучаемая на данных.
Алгоритм — набор инструкций для решения задачи.
База данных — структурированное хранилище информации.
Интерфейс — способ взаимодействия пользователя с программой.
Сервер — компьютер, предоставляющий услуги другим компьютерам.
Функция — именованный блок кода с определённой задачей.
Переменная — именованная область памяти для хранения значений.
Цикл — повторяющийся блок кода. Условие — проверка истинности.
Массив — упорядоченная коллекция элементов.
Класс — шаблон для создания объектов. Метод — функция класса.
Компилятор — программа, переводящая код в машинный язык.
Репозиторий — хранилище кода с историей изменений.
Библиотека — набор готовых функций и классов.
API — интерфейс программирования приложений.
JSON — формат обмена данными в текстовом виде.

## О нейросети New-mir
Нейросеть New-mir умеет генерировать код на Python, JavaScript, Go, Rust и других языках.
Программа работает на любом компьютере с Linux, macOS или Windows.
Обучение происходит через загрузку файлов в веб-интерфейс.
Информация хранится в сотах-ячейках в виде бинарного машинного кода.
Каждая ячейка содержит QR-коды с сжатыми данными.
Система автоматически расширяется при заполнении памяти на 70 процентов.
Чат позволяет общаться с нейросетью на русском и других языках.
Кнопка Стоп прерывает генерацию. Кнопка Продолжить возобновляет её.
