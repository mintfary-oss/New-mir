📖 Как пользоваться New-mir

Что такое New-mir?
New-mir — локальная нейросеть с веб-интерфейсом, работающая без интернета. Внутри — два движка: GPT-2 (124M параметров, чат) и NeuralCodeGen nano (145K параметров, генерация кода). Данные хранятся в «сотах-ячейках» (honeycomb memory) в виде бинарных QR-кодов.

Вкладка ⬡ Обучение
Загружай любые файлы — нейросеть обучится на текстовом содержимом и сохранит данные в honeycomb-памяти в виде бинарных QR-кодов.
Поддерживаемые форматы
Код: .py .js .ts .go .rs .c .cpp .java .cs .rb .php .swift .kt .sh .lua
Модели: .pt .bin .npz .h5 .gguf .safetensors
Архивы: .zip .tar.gz .7z .rar
Документы: .pdf .docx .txt .md .csv .json .yaml .xml
Медиа: .mp4 .mp3 .wav .png .jpg — всё принимается, текст извлекается где возможно
Процесс обучения
1. Файл конвертируется в бинарный поток (Layer 4)
2. Сжимается (Layer 3 — LZ4/Brotli/Zstd/GZip/лучший алгоритм)
3. Кодируется в QR-слоты (Layer 2)
4. Записывается в соту-ячейку honeycomb (Layer 1)
5. Текстовое содержимое отправляется на fine-tune нейросети (1 эпоха)
💾 Сохранение обучения
Нажми Сохранить обучение — веса и соты запишутся на диск (в Docker volume) и переживут перезапуск контейнера. Без сохранения данные живут только в RAM.
Авто-расширение: при заполнении 70% памяти автоматически создаётся новый блок из 65 536 сот-ячеек.
Вкладка Code Gen
Генерация кода через nano NeuralCodeGen (145K параметров) с RAG-lite — перед генерацией ищет в памяти релевантные фрагменты из обученных файлов и использует их как контекст.
ПараметрОписание
Mode: PromptДать начало кода — модель продолжит (например: def sort_list(lst):)
Mode: DescriptionОписать задачу на русском или английском — модель сгенерирует код с нуля
LanguagePython / JavaScript / TypeScript / Go / Rust / Bash
Max tokensМаксимальная длина генерации (16–1024)
Temperature0 = детерминированный, 1 = творческий/случайный
Пример промпта: def fibonacci(n: int) -> list[int]: """Вернуть первые n чисел Фибоначчи."""
RAG-lite: если до этого ты обучил нейросеть на своих файлах, Code Gen автоматически найдёт похожие фрагменты и использует их как подсказку — код будет учитывать твой стиль и архитектуру.
Convert — любой файл в бинарный поток
Перетащи или выбери файл — получишь: бинарное представление (0/1), степень сжатия, MIME-тип и текстовый превью если файл текстовый.
Compress — сжатие текста
Вставь текст → выбери hint (auto/text/binary) → получишь бинарный поток и коэффициент сжатия. Кнопка Estimate показывает сравнение всех алгоритмов без реального сжатия.
QR Encode — кодирование в QR-слоты
Текст разбивается на QR-код блоки, каждый получает уникальный ID. Первый QR-код показывается как PNG-изображение.
Memory — статистика памяти
Нажми Refresh — увидишь количество сот-ячеек в RAM, суммарный объём данных, список последних ячеек по ID.
