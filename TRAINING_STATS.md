> Этот файл обновляется автоматически после каждой сессии обучения.
> Персистентные данные хранятся в `data/training_stats.json`.

## Встроенные знания (seed-данные)

При первом запуске программа автоматически обучается на встроенных данных:

### Русский язык (`data/seed/russian_intro.txt`)
- Базовая лексика и грамматика
- Числа, времена, падежи
- Распространённые фразы и конструкции
- Объём: ~5 000 символов

### Язык программирования Rust (`data/seed/rust_basics.rs`)
- Базовый синтаксис (переменные, функции, структуры)
- Управление памятью (ownership, borrowing)
- Типы, обобщения (generics), трейты
- Стандартная библиотека
- Объём: ~4 000 символов

### Мультиязычный корпус (`data/seed/multilingual.txt`)
- Английский язык — базовые конструкции
- Немецкий язык — основные фразы
- Французский язык — базовая грамматика
- Испанский язык — распространённые слова
- Японский язык — базовые выражения
- Китайский язык — часто употребляемые фразы
- Объём: ~3 000 символов

### Примеры кода Python (`data/seed/python_examples.py`)
- Базовые алгоритмы (сортировка, поиск)
- Классы и наследование
- Асинхронное программирование
- Декораторы и генераторы
- Объём: ~4 000 символов

## Что умеет программа

### Генерация кода (вкладка Code Gen)
- Python, JavaScript, TypeScript, Go, Rust, Bash
- Режим подсказки (product prefix) и режим описания (natural language)
- Обучается на загруженных пользователем файлах с кодом

### Чат (вкладка Чат)
- Диалог на русском, английском и других языках
- Бесконечная генерация без ограничений
- Кнопка Стоп — пауза в любой момент
- Кнопка Продолжить — возобновление с места остановки
- Кнопка ▶ Проверить всё — авто-тест всех возможностей

### Обучение (вкладка ⬡ Обучение)
- Поддержка любых типов файлов
- Кнопка "Загрузить из сети" — данные с публичных GitHub репозиториев
- Хранение в сотах-ячейках (машинный код 0 и 1 через QR-слоты)
- Авторасширение памяти

### Конвертация (вкладка Convert)
- Любой файл → бинарный машинный код (0 и 1)
- Поддержка: текст, PDF, DOCX, аудио, видео, изображения, архивы, код

### Сжатие (вкладка Compress)
- LZ4 — быстрое сжатие
- ZSTD — высокая степень сжатия
- zlib — универсальное сжатие
- Delta+ZSTD — дельта-кодирование для похожих данных
- Автовыбор лучшего алгоритма

### QR-коды (вкладка QR Encode)
- Кодирование любого текста в QR-матрицу
- PNG-экспорт QR-кода
- Хранение данных в QR-слотах памяти

## История сессий обучения

*Загружается из `data/training_stats.json`*

При запуске программы данные о каждой сессии обучения записываются в
`data/training_stats.json`. Формат:

```json
{
  "sessions": [
    {
      "session_id": "abc123",
      "timestamp": "2026-07-25T10:00:00",
      "files_trained": 3,
      "cells_written": 3,
      "total_cells": 7,
      "fill_percent": 0.01,
      "shards": 1,
      "source": "user_upload"
    }
  ],
  "total_files_ever": 10,
  "total_cells_ever": 10,
  "seed_loaded": true,
  "seed_loaded_at": "2026-07-25T09:00:00"
}
```

## Производительность

| Метрика | Значение |
|---|---|
| Вычислений в минуту | до 10 млрд (зависит от оборудования) |

| RAM GPT-2 (base) | ~600 МБ |
| Поддерживаемые ОС | Linux, macOS, Windows (через Docker) |
| Минимальные требования | 1 ГБ RAM, 1 CPU |
